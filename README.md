# Balap Hafalan Qur'an — MI At-Taqwa

Game web balap hafalan untuk materi Al-Zalzalah sampai Al-Fil.

## Fitur
- Mobil dikendalikan siswa menuju 10 pos pemeriksaan.
- Soal muncul ketika mobil tiba di pos.
- Audio tilawah Syekh Abdul Basit tersedia pada susun ayat, sambung ayat, sambungan antarsurat, dan tebak surat.
- Audio membutuhkan koneksi internet.

## Publikasi
Unggah seluruh isi folder ini ke root repository GitHub Pages, lalu aktifkan Pages dari branch `main` dan folder `/root`.
