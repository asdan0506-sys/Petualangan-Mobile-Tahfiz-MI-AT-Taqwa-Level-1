# Balap Hafalan Qur'an — MI At-Taqwa (3D)

Versi 3D browser dengan kamera kejar dari belakang mobil, lintasan melengkung, pepohonan, gerbang checkpoint, HUD kecepatan, kontrol gas/rem/belok, serta seluruh soal dan audio hafalan dari versi sebelumnya.

## Menjalankan
- Jalankan melalui web server (misalnya GitHub Pages), bukan membuka file HTML langsung.
- Three.js dimuat dari CDN jsDelivr, sehingga perlu internet.
- Audio tilawah juga memerlukan internet.

## Publikasi GitHub Pages
Unggah seluruh isi ZIP ke root repository, lalu commit. Pastikan `index.html`, `service-worker.js`, logo, ikon, dan manifest ikut diperbarui.
