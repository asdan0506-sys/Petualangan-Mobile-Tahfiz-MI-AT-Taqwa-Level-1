# Balap Hafalan Qur'an MI At-Taqwa — 2.5D Joystick

Versi ini memakai canvas 2D dengan perspektif pseudo-3D sehingga tidak membutuhkan Three.js/WebGL.
- Kamera visual dari belakang mobil.
- Joystick virtual: dorong ke atas untuk gas, kiri/kanan untuk kemudi, tarik ke bawah untuk rem.
- Soal dan audio tilawah tetap dari versi sebelumnya.
- Audio memerlukan internet.

Unggah seluruh file ke root GitHub Pages dan commit perubahan.
