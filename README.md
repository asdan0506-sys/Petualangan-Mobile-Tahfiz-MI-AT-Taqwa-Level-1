# Balap Hafalan Qur'an

Website game mobile satu pemain, tanpa login dan tanpa database.

## Terbitkan gratis dengan GitHub Pages
1. Masuk ke https://github.com dan buat repository baru bernama `balap-hafalan-quran`.
2. Pilih **Public**, lalu buat repository. Tidak perlu menambahkan README.
3. Pada repository, pilih **Add file → Upload files**.
4. Unggah semua isi folder ini: `index.html`, `manifest.json`, `service-worker.js`, dan `icon.svg`.
5. Tekan **Commit changes**.
6. Buka **Settings → Pages**.
7. Pada **Build and deployment**, pilih **Deploy from a branch**.
8. Pilih branch **main**, folder **/(root)**, lalu tekan **Save**.
9. Tunggu beberapa menit. Link game akan berbentuk:
   `https://NAMA-AKUN.github.io/balap-hafalan-quran/`

Bagikan link tersebut ke grup siswa. Siswa tidak perlu login.

## Pasang di layar utama HP
- Android: buka link di Chrome → menu ⋮ → **Tambahkan ke layar utama** / **Install app**.
- iPhone: buka link di Safari → tombol Share → **Add to Home Screen**.

## Catatan
Fitur pengenalan suara Arab bergantung pada dukungan browser dan izin mikrofon. Penilaian suara di versi ini adalah perkiraan teks ucapan, bukan pemeriksaan tajwid/makhraj yang akurat. Uji bacaan dengan guru sebelum digunakan sebagai nilai resmi.
